# EDUARDORB WORLD — Documentation standard

Every public software product should have a README with purpose, current status, version, requirements, installation, privacy and limitations, license, support and official download link.

Maintain CHANGELOG.md for version changes, SECURITY.md for responsible reporting, and appropriate third-party notices. Do not publish sensitive information in public issues. Use the shared palette and banner style; client branding remains independent.

Use Portuguese for Brazilian user-facing instructions and English where useful for international audiences. Keep translations consistent. Report tests honestly and distinguish static validation from real browser tests and security audits.

For projects still in development, publish only a high-level concept or approved roadmap. Do not make unverified feature claims.
